# Práctica: Algoritmos de Búsqueda y Optimización en la CDMX

Repositorio oficial para el proyecto de Inteligencia Artificial (ESCOM), enfocado en la implementación, comparación y optimización de algoritmos de búsqueda ciega, informada y metaheurísticas aplicados a la red vial de la Ciudad de México.

## Requisitos e Instalación

Asegúrate de tener instalado **Python 3.10 o superior**. Para instalar las dependencias necesarias del proyecto, ejecuta el siguiente comando en tu terminal:

```bash
pip install osmnx folium pandas matplotlib networkx tabulate
